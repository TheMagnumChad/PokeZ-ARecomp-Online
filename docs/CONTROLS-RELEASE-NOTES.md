# v0.1.32 — Native keyboard and mouse controls

- Snappy mouse camera, including Poke Ball aim and zoom return.
- Modern keyboard defaults, remappable key glyphs and automatic input prompts.
- Native menu hover/click, independent list scrolling, Box drag-and-drop and item giving.
- Shop/clothing selection stays correct after scrolling and on later clothing tabs.
- Clickable Change Moves, menu tabs and system dialogs; outside-click context dismissal.
- Direct I/B/P/O shortcuts, Tab toggle lock-on, party wheel/middle-click and map controls.
- Title screen: Press any key to start. Error reporting directs players to LumioseOnline Discord.

**Windows:** the full ZA-Recomp-windows.zip includes the launcher, setup/compiler
tools, Python, runtime dependencies and the normal bundled mod/reference setup.
Existing players can use Update now. Fresh players should extract the whole
folder and open Lumiose Online.exe with their own game files (2.0.2 update/DLC).
The first launch refreshes game code and control glyphs; saves and custom bindings remain.

The controls were accepted after owner testing. Packaging checks cover content,
prompt generation, archive integrity and the one-time refresh. Confirmed gameplay
controls were not broadly retested. The separate graphics changes are not included.
Linux remains unchanged; this release provides no new Linux controls binary.

Please report bugs in the LumioseOnline Discord. Game ROMs/assets, generated
game libraries, caches, saves and player settings are not included.
